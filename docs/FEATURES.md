# Features

## Core Features
- **Create Todo**: Add new tasks with title, description, priority, and due date.
- **Read Todo**: View a comprehensive list of all tasks.
- **Update Todo**: Edit existing task details.
- **Delete Todo**: Remove a task permanently (with confirmation dialog).
- **Todo Details**: View in-depth information about a specific task on a dedicated page (accessed via `?id=...` query parameter).
- **Status Management**: Move tasks between `TODO`, `IN_PROGRESS`, and `COMPLETED`.
- **Priority**: Assign `LOW`, `MEDIUM`, or `HIGH` priority to tasks.
- **Search**: Filter tasks by title or description.
- **Filtering**: View tasks by specific status or priority.
- **Sorting**: Order tasks by creation date, due date, or priority.
- **Responsive Design**: Flawless experience on mobile, tablet, and desktop.

## UX Features
- **Loading States**: Skeletons and spinners to indicate data fetching.
- **Empty States**: Clear visuals when no tasks exist or search yields no results.
- **Error States**: Graceful error handling and user-friendly messages.
- **Form Validation**: Immediate feedback on invalid inputs using React Hook Form and Zod.
